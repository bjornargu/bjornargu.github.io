Campus Menu Chrome Extension

Completed

Lightweight browser popup delivering cafeteria menus with multi-campus and bilingual support.

System Overview

A client-side browser extension built to eliminate manual navigation to student welfare diner pages. The extension asynchronously fetches cafeteria HTML, extracts meal data via client-side DOM parsing, applies date-aware meal highlighting, and persists user preferences.

  • Client-Side Scraping: Asynchronously requests weekly menu endpoints and parses raw markup using the browser's native DOMParser.
  • Campus & Day Routing: Splits parsed items into regional arrays (Halden vs. Fredrikstad) and automatically highlights today's meal during weekdays.
  • Localization (i18n): Toggles between Norwegian and English meal feeds with corresponding locale labels and dynamic flag icons.
  • State Persistence: Leverages chrome.storage.local to preserve campus and language settings across browser sessions.
