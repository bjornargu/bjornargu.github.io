Automated host-level intrusion detection, live intelligence enrichment, and defensive response.

System Overview

A lightweight security orchestration pipeline running locally on Linux that monitors SSH telemetry and simulated web application logs in real time. It automates threat intelligence enrichment, synthesizes incident context using Gemini 3.8, and autonomously isolates attackers at the host firewall level.

  • Log Ingestion: Continuous tailing and regex parsing of authentication streams (FastAPI logs/alerts.log and systemd journalctl -t sshd).
  • Deterministic Enrichment: Queries AbuseIPDB API for baseline confidence scores and historical reporting volume.
  • AI Context & Triage (Gemini 3.8): Correlates threat telemetry, classifies attack patterns, and generates structured Tier 1 incident briefs.
  • Automated Mitigation: Dynamically injects timed DROP rules into Linux `iptables` and dispatches alerts via webhook.
